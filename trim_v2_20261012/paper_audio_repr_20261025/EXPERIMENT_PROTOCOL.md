# MOSEI 音频表示对照：沿用现有论文 TRIM 主干

本轮为可用原始媒体子集上的探索性验证实验。数据缺失尚未解决，不能将本轮数值直接替换论文完整数据主表，也不能将验证集差值写作测试集提升。

## 论文依据

依据 Overleaf_sync_fix_20261012_zip4/sections/method-new.tex；该源文件原样归档在 provenance/method-new.tex。模型直接调用 audit_av_core_20261012/model_legacy.py 的 E2EMSAModel，冻结副本位于 _paper/model_legacy.py。_paper/model_tools.py 提供与原 forward 对齐的缺失模式推理。

保留 BERT CLS、256 维投影、三路单 token 双层编码器、可学习缺失占位、T←A/A←T/V←T 三个门控、三个摘要 token、双层多模态编码器及分类头。保留独立 A/V 训练缺失概率 0.15，文本始终保留。保留原 CE、NCE、OT 和标量正则项；不引入 v2 的条件风险、单模态 CE、蒸馏或残差融合。

沿用历史细节：A/V 对所有存储帧求均值，包括补零位置；NCE 含 TA/TV，缺失样本也进入辅助项；两路 OT 共用 ot_ta；候选 AMA 权重未乘入损失。这些项目不在本轮同步修正，以免混淆音频表示的效果。

## 数据与对照

使用 MOSEI/Processed/aligned_50.pkl，非中性正负二分类，保留原 train/valid 划分。媒体存在且非空是唯一额外纳入条件；按标签或预测质量筛选样本均不允许。记录各 split 的完整可用率、类别计数、排除清单、选中 ID 和媒体 SHA256。解码失败直接报错，不自动删除样本。所有组共享选中样本、BERT、视觉输入、参数数量与初始化种子。

本地预检显示 train 可用 6065/12786（负 3205、正 2860），valid 可用 572/1438（负 301、正 271）。缺失 train 的负/正计数为 1533/5188，缺失 valid 为 205/661；可用媒体有明显类别选择偏差。本轮只能解释共同可用子集上的相对效果。远程独立核验，不把本地可用数量强加给远程，也不按类别比例再筛选 pilot 数据。

默认 seed=42，四组均从同一预训练 BERT 重新训练；不是在不同父模型上追加模块。每个 seed 的非 BERT 初始化 SHA256 必须相同。

BERT 预检比较实际配置参数而非单独依据 JSON 文件字节：使用同一 BertConfig 解析双方默认值，仅忽略保存版本、保存路径与 architectures 等元信息，并统一 dtype 字段别名。保留配置文件原始与参数化 SHA256，随后逐一核验全部 199 个参考权重张量；真实参数或权重改变仍会停止。

|组|音频输入|目的|
|---|---|---|
|paper_original|论文原始声学均值|子集论文参照|
|paper_normalized|原始声学均值，训练集逐维标准化|检查标准化本身的收益|
|panns_projected|PANNs 2048 维嵌入，训练集标准化，固定随机投影至原音频维度，再训练集标准化|保持可训练主干形状，检查通用音频内容表示|
|panns_shuffled|上一组特征在 train/valid 各自固定无不动点置换|音频与样本对应关系的负对照|

随机投影种子固定为 20261025，元素为 N(0,1)/sqrt(2048)，不利用情感标签或验证分布拟合。统计量只从本轮选定训练样本计算，保存为 representation_stats.npz。打乱组保留各 split 的音频分布但破坏样本对应，不使用验证标签选择置换。投影会损失信息；阴性结果不等于原始 2048 维表示无效。

PANNs 使用已校验的 AudioSet Cnn14 权重，冻结，不用情感标签微调。沿用上次 probe 的单声道 32kHz、10 秒窗口、5 秒步长、短音频尾部补零、窗口嵌入均值；没有改动短音频处理以追逐结果。AudioSet 是额外外部预训练资源，需在未来论文对照中披露。环境事件概率仅留作诊断，不采用枪声/爆炸声直接决定情绪的规则。

## 训练与判断

pilot：BERT 冻结 5 轮、最后两层解冻 8 轮、全部解冻 7 轮。batch=8、梯度累积 4、FP32、关闭 cuDNN/TF32、梯度裁剪 1。AdamW 权重衰减 0.01。三阶段 BERT 学习率分别 0/2e-5/1e-5，投影器 3e-4/5e-5/5e-5，其他层 3e-4。余弦调度与 10% warmup。最后不足一个梯度累积组时按实际 microbatch 数归一化，与审计重训器一致。

按全部阶段中最高的 TAV 验证 Macro-F1 选单个 checkpoint，各阶段进入下一阶段前恢复该阶段最佳权重。与论文保持一致，不按四条件均值或测试集选择。报告 T、TA、TV、TAV；额外报告零音频仍标记为可用的 TAV 诊断。各组联合训练会改变文本参数，所以 T/TV 的差值也是必须报告的代价。

主比较为 panns_projected 对 paper_original，同时查看 paper_normalized 以及 panns_shuffled。先观察 TAV/TA 收益和 T/TV 退化；单 seed、小验证集上的正差不足以证明论文结论。后续若有信号，再预注册多 seed、补全媒体并进入锁定测试评估。本脚本没有测试集评估入口。

smoke：训练和验证各抽 16 条均衡样本，三个阶段各 1 轮，四组均运行，用于检查工程。smoke 的特征统计只使用 smoke 训练样本，结果不得合入 pilot。

## 运行与复核

remote_paper_audio.sh start 自动后台启动 smoke，成功后继续 pilot，日志与 PID 由脚本创建。共享上一级 logs/suite.lock，防止与同项目其他脚本并发。失败后修复环境可再次 start，校验输入与配置后按完整 epoch 恢复；配置或媒体变化需使用新输出目录。

每轮保存优化器、调度器、模型、数据顺序与随机状态。每个任务结束复算选中验证分数、原 forward 一致性、缺失音频输入无关性。汇总器从逐样本预测重新计算指标，比较 ID/标签/参数数量/初始化并导出小 ZIP，不包含模型权重或原始视频。
