# IEMOCAP 六分类补充实验

## 研究问题及范围

在当前三个情感极性数据集之外，检验 TRIM 在六分类情感任务中的表现，并比较共享输入和训练条件下的文本模型、简单融合与 TRIM。主要结果为五个训练种子的测试集 Macro-F1 均值及样本标准差，同时保留 Accuracy、Weighted F1、UAR、NLL 与多分类 Brier 分数。效果方向由实际运行结果决定。

这一扩展使用项目已有 IEMOCAP 文件，测试会话不进入本轮模型拟合或选择。项目已有 IEMOCAP 使用记录，音视频预提取器的训练历史也未独立确认，因此不作“从未使用的外部数据”或盲测主张。这是固定会话划分，不与使用不同特征和五折协议的文献结果直接比较。

## 数据和输入

固定输入为项目根目录下 `MELD和IEMOCAP的pkl数据集/iemocap_multimodal_features.pkl`，文件 SHA-256 必须与 `provenance/data_reference.json` 一致。12 个字段的解释与公开的 [DFGCN 加载代码](https://github.com/yuntaoshou/DFGCN/blob/main/dataloader.py)对应；这一对应只确认格式，不证明预提取权重的训练来源。

保留原始六类标签编码 0–5，不合并为正负极性。训练使用 Session 1–3，验证使用 Session 4，测试使用 Session 5。按对话 ID 及话语 ID 检查交集。实际文件核查结果为训练 4,298 条（90 段对话）、验证 1,512 条（30 段对话）、测试 1,623 条（31 段对话）。原生视觉全零分别为 21、0 和 58 条，三个部分的原生音频均非全零。

文本使用原始转写，以项目原有 `bert_en/vocab.txt` 和 `BertTokenizer(do_lower_case=True)` 重新分词，长度固定为 64（含特殊标记），右侧补齐及截断。四组随文件提供的 1,024 维文本表示完全不作为模型输入。所有方法加载同一经逐张量校验的英语 BERT，使用最后一层 CLS；分词词表单独校验摘要。

音频为 1,582 维、视觉为 342 维的话语向量。逐维均值和标准差仅在 Session 1–3 的原生非零行拟合；标准差下限为 1e-6。全零行保留零值并标为缺失，不参与归一化统计。验证和测试沿用训练统计量。该预处理属于跨语料适配，不能称为原有三数据集完全相同的特征管线。

## 模型及训练

五种方法为 `trim`、`bert_mlp`、`concat`、`additive` 和 `budget_mlp`。TRIM 沿用已验证的原实现，包括单模态编码、三个有向门控交互块、多模态编码及三个摘要 token；改变输入维度和六分类输出维度。每个话语的音频与视觉各为一个 token，不主张帧级时序注意力。`concat` 共享 TRIM 投影及单模态编码，随后拼接分类；`additive` 平均三个独立分支的六维 logits；`budget_mlp` 的融合及分类部分名义参数量与 TRIM 相差小于 1%。这种匹配不表示有效计算量或有效参数完全相同。`bert_mlp` 为真正的 BERT CLS 分类器，不包含缺失音视觉分支。

种子固定为 101、202、303、404、505，共 25 个训练任务。相同种子下，多模态模型的公共分支初值、数据顺序及模态丢弃随机流相同。缺失占位在投影后、单模态编码前替换。所有方法均使用相同文本和对应输入，原生缺失掩码与训练随机丢弃取交集。

训练分三阶段：冻结 BERT 训练 5 轮；解冻最后两层训练 8 轮；全解冻训练 7 轮。每阶段从上一阶段验证最优权重继续，并在全部 20 轮中按 Session 4 完整输入 Macro-F1 选出全局最优权重，完全相同分数取较早轮次。批大小为 16，梯度累积 2 步，FP32，AdamW，权重衰减 0.01，梯度范数裁剪为 1。学习率及余弦预热设置见机器可读协议与训练脚本。

六类交叉熵的类别权重仅由训练频数计算：对 `sqrt(N/(6*n_c))` 归一化为均值 1；标签平滑 0.05。四个多模态方法使用相同的 `CE + 0.02*InfoNCE + 0.02*batch OT`，文本模型仅使用 CE。保留旧实现的批次配对辅助目标，包括缺失占位参与批次计算；不将目标差异解释为纯粹的网络结构差异。旧实现中不起作用的独立 AMA 标量未带入新实验，不作自适应加权贡献主张。

## 测试及诊断

25 个任务完成后统一封存权重摘要，再评估 Session 5。测试条件为完整输入、仅文本、文本加音频、文本加视觉，以及音视觉数值置零但标为存在。最后一种条件与显式缺失分开报告。

错配诊断各重复 20 次：跨对话音频、跨对话视觉、跨对话成对音视频，以及同对话成对音视频。跨对话映射为禁止同对话的双射，同对话映射为非恒等循环置换；只有至少两条话语的对话参加后者。映射不读取标签，在模型和训练种子间共享。音视频联合错配保留两者内部配对关系，原生缺失状态随供体一同交换。对照和干预在同一批合格样本上比较；重复置换不作为独立训练种子。

经验多模态加性投影（EMAP）采用 [Hessel 和 Lee（2020）](https://aclanthology.org/2020.emnlp-main.62/)的诊断思路，以 `T | (A,V)` 分组，在每条话语六类 logits 减去类别均值后进行投影。以两个独立、无标签抽取的 64 锚点集合近似经验乘积分布，两个投影先取均值，再作 argmax 和评分。保留各集合及其前 32 个锚点的结果，报告近似误差诊断。该分析检验文本与音视频组合之间的非加性交互，不分解音频与视觉组合内部的交互。文本模型和结构加性模型应在投影后保持输出，为实现提供校验。

配对区间用 2,000 次测试对话重采样，另报告交叉重采样五个训练种子与测试对话的结果。每次都从混淆矩阵重新计算六类 Macro-F1。区间为逐项区间，条件限于 Session 5 及其两位说话人，不能据此作说话人总体推断，也不作多重比较校正后的显著性主张。全部预定对照均返回，不按测试集结果删减方法或挑选种子。

## 软件及返回文件

软件要求为 Python 3、PyTorch 2.4.x 和 Transformers 4.49.0。启动时检查当前 NumPy 与 PyTorch 能否相互转换数组和张量，并记录实际 NumPy 版本。使用项目已有 BERT 权重，离线运行。GPU 任务串行运行，与前一补充包共享文件锁。需要约 17.5 GB 可用空间保存检查点和当前优化器缓存。

逐轮结束保存模型、优化器、调度器及随机状态。恢复时校验输入、源码和协议摘要，从最后一个完整轮次继续。返回压缩包包含各条件预测、逐种子指标、全部对照区间和检查记录，不包含原始数据或模型权重。任何源文件或协议修改均要求新建运行目录，不在原结果上覆盖协议。
